# Lecture Summarizer

An AI-powered lecture summarizer built with Streamlit that converts lengthy lecture notes into concise, meaningful bullet points using a Large Language Model (LLM).

## Features

- Upload or paste lecture text
- AI-generated structured bullet points
- Removes repetition
- Extracts key concepts
- Simple Streamlit interface

## Technologies Used

- Python
- Streamlit
- Requests
- LLM API


## Future Improvements

- PDF upload
- DOCX support
- Download summary
- Multi-language summarization
- Speech-to-text integration
